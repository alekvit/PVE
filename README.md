## Лицензии

Проект распространяется под лицензией **[MIT](LICENSE)** (см. корневой файл `LICENSE`).

Для отдельных компонентов в их папках размещены копии лицензии. Если компонент имеет отличную от общей лицензию, это явно указано ниже:

| Компонент | Лицензия | Ссылка |
| --- | --- | --- |
| Traefik | MIT | `traefik/LICENSE` |

> Если в будущем какой‑либо компонент будет использовать другую лицензию, она будет указана отдельно в таблице и в файле `LICENSE` внутри папки компонента.

## Как использовать

1. Клонируйте репозиторий:

   Гитверс
   `git clone https://gitverse.ru/alekvit/PVE.git`

   Гитхаб
   `git clone https://github.com/alekvit/PVE.git`
2. Перейдите в нужную папку компонента, например:

   `cd PVE/traefik`
3. Ознакомьтесь с документацией компонента и действуйте согласно инструкции.
